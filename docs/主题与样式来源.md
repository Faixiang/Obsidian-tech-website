## 二、背景色：5 級深色縱深

### 2.1 品牌規範 §3.1 定義的五級

| 層級 | 色值 | 角色 |
|---|---|---|
| 極夜藍 | `#02020A` | 全局最深基底、頁腳 |
| 深空藍（主背景） | `#0B1F3A` | 主背景、導航、Hero |
| 藍灰 | `#16294A` | 次級區塊背景（產品區、內容區） |
| 石墨灰 | `#1C2530` | 卡片／面板底 |
| 金屬藍灰 | `#1E2A44` | 卡片 hover、高亮面板 |

**規則**：頁面至少使用 3 級深色形成縱深（基底 + 主背景 + 卡片層）；相鄰層級須可辨。

> **V1.1.1 修正**：藍灰原定 `#12233F`，與石墨灰 `#1C2530` 亮度差僅 **0.0009**，肉眼幾乎無法分辨。調整為 `#16294A` 後 ΔY 提升至 **0.0075**。其餘四級皆達標（極夜藍→深空藍 Δ0.0128、深空藍→藍灰 Δ0.0067、金屬藍灰 Δ0.0057）。

## 七、可讀性反差面板（最新一層）

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--readable-coral` | `#5C0F1B` | 青色區低對比正文的承載板（深酒紅） |
| `--readable-lime` | `#1E3A00` | 紫色區的承載板（深橄欖） |
| `--readable-ink` | `var(--white)` | 面板文字色（13.7:1 / 14:1+） |
| `--readable-tag-coral` | `#FF2B47` | 只做 3px 左線與小標籤 |
| `--readable-tag-lime` | `#84D000` | 只做 3px 左線與小標籤 |
| `--readable-panel-tint` | `rgba(255,255,255,0.05)` | 面板頂部微漸層 |

**演進過程（可寫入報告）**

1. 初版：滿版高飽和色（`#FF2B47` / `#84D000`）+ 深字，實測 **5.60:1** 合規
2. 使用者反饋「更看不清」→ 診斷為**眩光 + 邊緣振動**（面板亮度 0.234 vs 頁面 0.0008，差近 300 倍）
3. 修正：深色化反差 + 白字（13.7:1 / 14:1+），高飽和色只保留在 3px 細線

> **結論**：對比度合規 ≠ 易讀。亮度差與色振動同樣影響可讀性。

## 八、字體系統

| 項目 | 現值 | 來源 |
|---|---|---|
| 拉丁／數字 | **Inter**（自託管 woff2，400/500/600/700） | 排印重構時引入 |
| 中文 | **Noto Sans SC**（自託管子集，400/500/700） | 品牌規範 §4.1 |
| 字重上限 | 700（原康陶為 900） | 為降低模板感而收斂 |
| 字距 | ≤ 0.06em（原康陶 3–10px） | 同上 |
| 大小寫 | 正常大小寫（原全大寫） | 同上 |
| 數字對齊 | `font-variant-numeric: tabular-nums` | 取代等寬字體 |

**字級 6 級（品牌規範 §4.2，V1.1.2 修訂）**

| 層級 | 字號 | 字重 | 行高 |
|---|---|---|---|
| Display / H1 | 34–52px | 700 | 1.2 |
| H2 | 28px | 700 | 1.25–1.3 |
| H3 | 20px | 600 | 1.35–1.4 |
| 正文 | 16px | 400 | 1.65–1.75 |
| 輔助說明 | 12–13px | 400 | 1.5 |
| 英文標籤 Eyebrow | 11–12px | 500–700 | 1.4 |

> 康陶原始參數是「標題一律 900 極粗、字距隨字號反向遞減（108px 配 10px）、小字全大寫 + 3–4px 寬字距」——這套正是後來被判定「太 AI 感」而重構的部分。
